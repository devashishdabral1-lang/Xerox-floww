Xerox Flow · Aakhri update: 18 November 2026 · Terms dekhein

Ye policy batati hai ki Xerox Flow (QR se print order lene wala software) kaun si jaankari leta hai, kyun leta hai, aur uska kya karta hai. Ye customers (jo QR scan karke print order dete hain) aur dukaandar / owners (jo software use karte hain) dono par lagu hoti hai.

1. Customers ki jaankari

Jab aap order dete ho, hum ye lete hain:

  • Aapki upload ki hui file aur uska naam
  • Print settings (colour, paper size, sides, copies), pages ki ginti aur amount
  • Order ka ticket number aur samay

Hum aapse naam, phone number ya email nahi maangte. Aapka current ticket sirf aapke browser ki us tab mein yaad rakha jata hai, taaki refresh karne par wo na jaye.

2. Dukaandar ki jaankari

  • Email, dukaan ka naam, aur password (password hum seedha nahi dekh sakte; wo surakshit tareeke se hash hokar save hota hai)
  • Dukaan ki settings (rates), plan, trial aur subscription ki taareekh
  • Subscription payment ka record (amount, mahine, taareekh). Paisa UPI se seedha aapse humare paas aata hai, hum aapke bank ya card ki details nahi lete.
  • Dukaan ke saare orders ka record

3. Hum jaankari ka kya karte hain

  • Customer ki file sirf us dukaan ko dikhti hai jisko order diya gaya, taaki wo print kar sake.
  • Hum jaankari bechte nahi hain, aur vigyapan (ads) ke liye use nahi karte.
  • Order ka record (bina file ke) dukaan ke hisaab-kitaab ke liye rakha jata hai.

4. Files kab delete hoti hain

Customer ki file delivery ke baad delete ho jati hai, jab dukaandar order ko "Delivered" mark karta hai. Agar order deliver mark nahi hua, to file 24 ghante ke baad delete ki jati hai. Ye safai dukaan ke dashboard ke zariye hoti hai, isliye kabhi-kabhi (jaise dukaan ka dashboard kuch der band rahe) delete hone mein deri ho sakti hai.

Zaroori: aap jo file bhejte ho (jaise Aadhar, marksheet), wo dukaandar ko dikhti hai, kyunki wahi use print karta hai. Zyada sensitive documents sirf bharose ki dukaan par print karwayein.

5. Jaankari kahan rehti hai

Jaankari cloud servers par rakhi jati hai. Database aur files Supabase par, aur website Vercel par chalti hai. Page ke kuch hisse (jaise code libraries) jsDelivr aur cdnjs se load hote hain, jinhe aapka IP address dikh sakta hai. Files ek private storage mein rehti hain, jise sirf sambandhit dukaan dekh sakti hai.

6. Suraksha

Hum jaankari ko surakshit rakhne ke liye uchit upay karte hain (private storage, har dukaan ka alag access, login). Koi bhi internet system 100% surakshit nahi hota, isliye hum poori guarantee nahi de sakte.

7. Aapke adhikar

Aap apni jaankari ke baare mein puch sakte ho, use sudharwa sakte ho, ya hatwane ki maang kar sakte ho. Customers apni file ko jaldi hatwane ke liye dukaan se ya humse sampark kar sakte hain. Dukaandar apna account aur data hatwane ke liye humse kah sakte hain. Hum kanoon ke hisaab se jo rakhna zaroori ho, usko chhodkar baaki jaankari hata denge.

8. Badlav

Hum is policy ko badal sakte hain. Naya version isi page par upar ki taareekh ke saath dikhega.

Sampark ke liye dukaan ke counter par, ya Xerox Flow ke admin se baat karein.
